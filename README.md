# Eventible — static preview

A browsable snapshot of the Eventible demo, published with GitHub Pages:

**https://jeroendeleijer.github.io/eventible-preview/**

Every page here was rendered once and written to disk. You can browse the
events, the spaces, the categories and the public profiles. Signing up,
booking a ticket, checking people in and the organiser and admin dashboards
are not here, because those need the application running against a database —
links into them land on a page that says so.

This repository holds generated output only. It is rebuilt with
`tools/export_static.py` in the application's own repository, which is
private.

The photographs are placeholders — see `static/img/seed/CREDITS.md` for what
each one is and what it requires.
